# Algorithm Implementations in C++

This repository contains pure C++ implementations of classic computer science algorithms. It serves as a foundational codebase for understanding how algorithms work under the hood without relying on high-level standard library abstractions.

## 📝 Overview
Understanding algorithms at a lower level (C++) is crucial for optimizing performance-critical components in larger systems, such as custom inference engines for machine learning models or high-throughput data processing pipelines.

## 🛠 Contents
- **Sorting Algorithms:** QuickSort, MergeSort, HeapSort, and Radix Sort implementations.
- **Searching Algorithms:** Binary Search variations and heuristic-based search techniques.
- **Tree Algorithms:** Implementations of AVL Trees, Red-Black Trees, and standard Binary Search Trees.
- **Graph Algorithms:** Shortest path algorithms and network flow computations.

## 💻 Tech Stack
- **Language:** C++ (C++11/C++14/C++17 standards)
- **Concepts:** Pointers, Memory Management, Templates

## 🎯 Objective
To establish a strong theoretical and practical understanding of algorithm design, ensuring the ability to write computationally optimal code for academic and research-oriented engineering tasks.
